# Execute

작업 문서는 현재 작업 폴더 기준 `.goal/<goal>/`에서 관리한다.
`<goal>`은 사용자와 합의한 목표 폴더명을 재사용하고, 대상이 불명확하면 먼저 확인한다.

process.md에 따라 작업을 수행하고,
process-eval.md를 기준으로 진행 과정을 점검한다.

- 입력 문서가 없거나 필요한 내용이 부족하면 사용자에게 확인한다.
- 사용자 참여가 필요한 작업은 필요한 행동을 요청하고 결과를 확인한다.
- 필요하면 계획을 수정하되, 중요한 변경은 사용자와 합의한다.
- 수행한 작업, 점검 결과, 남은 사항을 보고한다.

목표 달성 여부에 대한 최종 평가는 Verify에서 진행한다.
다른 단계는 사용자가 요청할 때만 진행한다.
