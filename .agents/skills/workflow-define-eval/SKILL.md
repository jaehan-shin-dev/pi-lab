# Define — Goal Evaluation

작업 문서는 현재 작업 폴더 기준 `.goal/<goal>/`에서 관리한다.
`<goal>`은 사용자와 합의한 목표 폴더명을 재사용하고, 대상이 불명확하면 먼저 확인한다.

goal.md를 기반으로 평가가 필요한 항목만 골라
goal-eval.md를 나열식으로 작성한다.

각 항목에 대해 대응하는 목표 항목과 다음 내용을 명시한다.

- Criteria: 어떤 조건을 만족해야 성공인가?
- Method: 어떤 방법으로 확인할 것인가?
- Evidence: 어떤 증거로 판단할 것인가?

각 항목에 평가가 필요한 이유를 설명한다.
결정이 필요한 사항은 대안과 추천안을 제시하고 사용자에게 확인받는다.
goal.md가 없거나 필요한 내용이 부족하면 사용자에게 확인한다.

여기서는 평가 기준을 설계하며, 실제 검증은 Verify에서 진행한다.
다른 단계는 사용자가 요청할 때만 진행한다.
